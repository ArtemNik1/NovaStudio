# NovaStudio

Учебный сайт веб-студии: главная, страница о команде, портфолио и контакты. Написан на HTML, CSS и JavaScript. Вёрстка адаптивная, стили разделены на блоки по БЭМ.

## Посмотреть локально

Открой `index.html` в браузере или запусти сервер из корня проекта:

```bash
python -m http.server 8080
```

Сайт будет доступен по адресу http://localhost:8080. Устанавливать зависимости и собирать проект не нужно.

## Что где лежит

| Файл или папка | Содержимое |
| --- | --- |
| `index.html` | Главная страница и услуги |
| `about.html` | О студии и демонстрационная команда |
| `portfolio.html` | Примеры оформления проектов |
| `contact.html` | Контакты и форма |
| `css/blocks/` | Стили компонентов |
| `css/style.css` | Общие стили и подключение блоков |
| `js/main.js` | Мобильное меню и обработчик формы |

Команда и работы в портфолио демонстрационные. Форма показывает уведомление, но не отправляет сообщения на сервер.

Публикация на GitHub Pages настроена в `.github/workflows/static.yml` и запускается при изменениях в `main`.
