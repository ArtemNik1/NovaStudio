# NovaStudio

Личный сайт Артёма Николаиди: услуги веб-разработки, открытые проекты и контакты.

**[Открыть сайт](https://artemnik1.github.io/NovaStudio/)**

Четыре страницы, адаптивная вёрстка, CSS по БЭМ и JavaScript без сборщика. Навигация поддерживает клавиатуру, закрытие по Escape и отключение анимации по системной настройке.

## Запуск

```bash
python -m http.server 8080
```

Откройте http://localhost:8080. Для публикации используется `.github/workflows/static.yml` и GitHub Pages.

## Контактная форма

Форма проверяет данные и открывает почтовое приложение с подготовленным письмом. Пользователь сам подтверждает отправку. Серверной отправки и скрытого сбора данных нет; страница не показывает ложное сообщение «отправлено». Если почтовое приложение не настроено, можно скопировать текст и написать напрямую.

## Проекты

В подборке представлены реальные репозитории: `po-delu`, `Showcase` и этот сайт. Учебные и демонстрационные работы обозначены явно. Отзывы, коммерческие результаты и показатели опыта не выдумываются.

Перед публикацией изменений проверьте четыре страницы на телефоне и компьютере, ссылки, мобильное меню и подготовку письма.
