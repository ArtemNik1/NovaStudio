# NovaStudio — многостраничный сайт на БЭМ

Учебный проект веб-студии с вёрсткой по методологии **БЭМ** (Блок, Элемент, Модификатор).

## Структура проекта

```
├── index.html          # Главная (4 экрана прокрутки)
├── about.html          # О нас
├── portfolio.html      # Портфолио
├── contact.html        # Контакты
├── css/
│   ├── style.css       # Точка входа
│   └── blocks/         # БЭМ-блоки
│       ├── header.css
│       ├── hero.css
│       ├── button.css
│       ├── section.css
│       ├── card.css
│       ├── footer.css
│       └── page.css
└── js/
    └── main.js
```

## Примеры БЭМ-классов

| Тип | Пример |
|-----|--------|
| Блок | `.header`, `.hero`, `.card` |
| Элемент | `.header__link`, `.hero__title`, `.card__icon` |
| Модификатор | `.button--primary`, `.header__link--active`, `.section--dark` |

## Страницы

- **Главная** — 4 полноэкранных секции: Hero, Услуги, Преимущества, CTA
- **О нас** — информация о студии и команде
- **Портфолио** — галерея проектов
- **Контакты** — форма обратной связи
